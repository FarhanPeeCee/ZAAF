# Zaaf Academy brand assets

| File | Use |
| --- | --- |
| `zaaf-logo-light.png` | For light backgrounds. 866 × 748, RGBA. |
| `zaaf-logo-dark.png` | For dark backgrounds. 844 × 766, RGBA. |

Both are the full lockup: the mark above the ZAAF wordmark with ACADEMY beneath.

## Notes for the website build

- These are raster files. **An SVG version of each is needed before the site is built** — the logo appears in the header on every page, and a PNG will look soft on high-density phone screens, which is how most visitors will see it.
- A square or horizontal variant of the mark alone, without the wordmark, will be needed for the browser icon, social profiles and the WhatsApp Business account.
- Neither file is trimmed to the artwork, so both carry transparent padding. Trim before use in a tight header.

See `docs/website-plan.md`, section 10, for how the identity is applied.
